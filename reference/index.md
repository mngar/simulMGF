# Package index

## All functions

- [`simGeno()`](https://mngar.github.io/simulMGF/reference/simGeno.md) :
  Function to simulate SNP matrix
- [`simPheno()`](https://mngar.github.io/simulMGF/reference/simPheno.md)
  : Function to simulate phenotypes
- [`simulFS()`](https://mngar.github.io/simulMGF/reference/simulFS.md) :
  Function to simulate full sib progeny genotype
- [`simulHS()`](https://mngar.github.io/simulMGF/reference/simulHS.md) :
  Function to simulate half sib progeny genotypes
- [`simulN()`](https://mngar.github.io/simulMGF/reference/simulN.md) :
  Function to simulate a SNP matrix, a phenotypic trait and the effects
  of associated SNPs.
- [`simulU()`](https://mngar.github.io/simulMGF/reference/simulU.md) :
  Function to simulate a random SNP matrix, phenotype and QTLs with
  their effects
